# skillscore-copy
Code and data accompanying the manuscript **"Quantifying advances in infectious disease forecast skill across seasons and pathogens"**. 
This repository reproduces the skill score evaluation of influenza and COVID-19 forecasts against a set of benchmark models (hindcast, naive baseline, random walk baseline, and trend baseline).

The pipeline pulls surveillance data and team forecasts from public forecast hubs, builds the benchmark forecasts, scores every model with the Weighted Interval Score (WIS) / logarithmic score, and produces the manuscript figures. 

## Requirements

### Python
Python 3.9+ with the packages in [`requirements.txt`](requirements.txt):

```bash
pip install -r requirements.txt
```

### R
R (4.x). Install all R dependencies with:

​```bash
Rscript install.R
​```

This installs the CRAN packages plus two GitHub-only packages
(`reichlab/covidData`, `reichlab/covidHubUtils`) used by `code/Collect observed data.R`.


### Running the code
- All R, .py and .ipynb scripts under code/ are written to run from the repository root. Start R / Jupyter with the repo root as the working directory.
The two notebooks in submission format sensitivity analysis/ are written to run from that folder (they reach the rest of the repo with ../).

- Raw team forecasts are not committed. They are regenerated by the pull steps below, which download from the public forecast hubs.

- Observed / truth surveillance data and the pre-computed scored forecasts/ and submission format sensitivity analysis/scores/ files are included, so the figure notebooks (Step 8) can be run directly if you do not want to regenerate everything.

## Pipeline
Steps 1–5 regenerate inputs; if you only want the figures from the committed scored forecasts/, skip to **Step 8**.

### Step 1 — Pull versioned (real-time) and final observed surveillance data
- `code/Collect observed data.R`
- `code/pull versioned data/pull_versioned_data_covid.R`
- `code/pull versioned data/pull_versioned_data_flu_hospitalization.R`
- `code/pull versioned data/pull_versioned_data_flu_ili.R`

### Step 2 — Pull hub forecasts
- `code/pull hub forecasts/get_covid_forecasts.ipynb`
- `code/pull hub forecasts/get_flu_hosp_forecasts.ipynb`
- `code/pull hub forecasts/get_ILI_forecasts.ipynb`

### Step 3 — Create hindcasts 
- `code/create hindcast/Create Hindcast COVID19.R`
- `code/create hindcast/Create Hindcast FluSight Hospitalizations.R`
- `code/create hindcast/Create Hindcast FluSight ILI.R`

### Step 4 — Create benchmark baseline forecasts
**a. Naive Baseline**
- `code/create naive baseline/naive_forecast_covid.R`
- `code/create naive baseline/naive_forecast_flu_hosp.R`
- `code/create naive baseline/naive_forecast_flu_ILI.R`

**b. Random Walk Baseline**
- `code/create random walk baseline.ipynb`

**c. Trend Baseline**
- `code/create trend baseline/ets_additive_damped_forecast_covid.R`
- `code/create trend baseline/ets_additive_damped_forecast_flu.R`
- `code/create trend baseline/ets_additive_damped_forecast_ili_logit_2003on.R`

### Step 5 — ILI submission-format sensitivity analysis 
- `bin-quantile_team-forecasts-ILI.ipynb` — converts ILI team forecasts to quantiles.
- `submission-format-sensitivity-analysis.ipynb` — produces the ILI binned / quantile-interpolation forecasts and the log / WIS score files in submission format sensitivity analysis/scores/ .

### Step 6 — Score all forecasts 
- `code/score forecasts/Score COVID-19 all teams.R`
- `code/score forecasts/Score COVID-19.R`
- `code/score forecasts/Score COVID-19 extended.R`
- `code/score forecasts/Score FluSight Hospitalizations.R`
- `code/score forecasts/Score Flusight hospitalizations extended.R`
- `code/score forecasts/Score Flusight ILI Quantiles.R`
- `code/score forecasts/Score Flusight ILI extended WIS.R`

### Step 7 — Baseline-model comparison for supplementary analysis
- `baseline model comparison/convert_cbase.py`, `convert_ibase.py`
- `baseline model comparison/Score cBase models.R`, `Score iBase models.R`
- `baseline model comparison/plot_season_mwis_single.py`
- Requires cBase.csv / iBase.csv (download separately; see the docstrings in convert_cbase.py / convert_ibase.py).

### Step 8 — Generate figures 
- `code/generate_figures_main-text.ipynb`
- `code/generate_figures_SI.ipynb`
